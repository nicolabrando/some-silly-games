# Some Silly Games 🎮

Una raccolta di giochini fatti in casa, scritti in HTML, CSS e JavaScript puro:
niente framework, niente build — ogni gioco è una pagina che gira direttamente
nel browser.

Dentro c'è un po' di tutto: strategia a turni (Risiko, Conquista Esagonale e le
loro varianti), un racing 2D con fisica e campionato (Apex), un platform
balneare a dieci livelli (Lido Runner), più i classici rivisitati — Breakout,
Wordle in italiano (Parolina) e Simon. Quasi tutti si giocano anche dal telefono.

Si parte da `index.html`, il menu con tutte le card, oppure aprendo direttamente
il file del singolo gioco.
